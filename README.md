# Midea — Мульти-сплит-системы (лендинг)

Статическая верстка страницы по макету Figma «Midea Товарный сайт» (Section 2).

## Структура

```
index.html      — разметка всей страницы
css/style.css   — стили (дизайн-токены Figma в :root)
js/main.js      — меню, аккордеоны, схема, форма, скролл
assets/         — экспортированные из Figma изображения и иконки
```

## Запуск

Открыть `index.html` в браузере — сборка не нужна.

## Шрифт

**Gotham Pro** (Regular / Medium / Bold) лежит в `fonts/` и подключён через
`@font-face`. Шрифт коммерческий — перед публикацией на боевой домен проверьте
наличие веб-лицензии. Для продакшена файлы стоит конвертировать в woff2
(вдвое легче TTF).

## Форма

Отправка формы — заглушка (`console.log` + экран «Спасибо»). Подключение
бэкенда описано в **INTEGRATION.md** (точка в `js/main.js`, формат данных,
honeypot, серверная валидация, событие аналитики `lead_form_submit`).

## Брейкпоинты

Резиновая верстка с опорными точками макета: 1440 / 1280 / 768 / 390
(media-запросы: 1279px / 1023px / 639px).

## Осознанные отступления от макета

- Стрелки галереи на карточках моделей не сверстаны: в макете по одному фото
  на карточку, стрелки были бы мёртвыми элементами. Ассеты стрелок лежат в
  `assets/arrow-*.svg` — если появятся дополнительные фото, галерею легко добавить.
- Плюс в аккордеоне и красные точки схемы нарисованы CSS (вместо SVG из макета),
  чтобы анимировать состояние; геометрия и цвета соответствуют макету.
- Тексты FAQ взяты из редакционного документа multipromo-faq_2 (1).docx
  (с правкой орфографии и типографики).
