# Интеграция лид-формы «Соберите свою мульти-сплит-систему»

Инструкция для бэкенд-разработчика. Фронтенд готов полностью: валидация,
маска телефона, ошибки, экран «Спасибо». Осталось подключить отправку данных.

## Где подключать

Файл **`js/main.js`**, обработчик `submit` формы `#leadForm` — ищите комментарий
`=== ТОЧКА ИНТЕГРАЦИИ С БЭКЕНДОМ ===`. Сейчас там `console.log('Заявка:', data)` —
замените его на отправку на ваш endpoint:

```js
fetch('/api/lead', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify(data)
})
  .then(function (r) { if (!r.ok) throw new Error(r.status); })
  .catch(function (err) {
    // на своё усмотрение: показать пользователю сообщение об ошибке
    console.error('Lead send failed', err);
  });
```

Экран «Спасибо» показывается сразу после этой точки (оптимистично).
Если нужно показывать его только после успешного ответа сервера — перенесите
блок с `form.classList.add('is-sent')` внутрь `.then()`.

## Данные формы

Объект `data` (все значения — строки):

| Поле | Что это | Возможные значения |
|---|---|---|
| `objectType` | Тип объекта (radio) | `Квартира` \| `Загородный дом` \| `Офис` \| `Нежилое помещение` |
| `rooms` | Количество комнат (radio) | `1` \| `2` \| `3` \| `4` |
| `city` | Город (текст) | непустая строка |
| `name` | Имя (текст) | непустая строка |
| `phone` | Телефон | всегда в формате `+7 000 000-00-00` (маска гарантирует) |

## Клиентская валидация (уже сделана)

- все поля обязательны;
- телефон: маска `+7 000 000-00-00`, ровно 10 цифр после кода,
  первая цифра кода не 0/1/2, буквы физически не вводятся;
- radio-группы всегда имеют выбранное значение (checked по умолчанию).

**Серверную валидацию продублируйте** — клиентскую можно обойти.
Регулярка для телефона: `^\+7 \d{3} \d{3}-\d{2}-\d{2}$` (или нормализуйте
до 11 цифр: `7` + 10).

## Антиспам

В форме есть honeypot-поле `website` (скрыто от людей стилями,
`tabindex="-1"`). Фронт не отправляет заявку, если оно заполнено, и удаляет
его из `data`. **На сервере тоже отклоняйте запросы с непустым `website`**,
если решите отправлять форму нативным POST вместо fetch. При необходимости
добавьте rate-limit по IP и/или капчу.

## Аналитика

Счётчик Яндекс.Метрики **112391106** уже установлен в `<head>` `index.html`
(webvisor, clickmap, trackLinks включены). При успешной отправке формы фронт
вызывает:

```js
ym(112391106, 'reachGoal', 'lead_form_submit');
```

Также при клике по любой кнопке «Подобрать» (шапка, мобильное меню, hero,
секция типов) уходит цель с параметром места:

```js
ym(112391106, 'reachGoal', 'cta_click', { place: 'header' | 'mobile_menu' | 'hero' | 'types' });
```

В интерфейсе Метрики нужно создать две **JavaScript-цели** с идентификаторами
`lead_form_submit` (лид, основная) и `cta_click` (клик по CTA,
микроконверсия). Дублирующие события уходят и в `dataLayer` (на случай GTM).

Страница размещается по адресу `https://air-midea.com/multipromo/` —
canonical и og:url уже прописаны на него.

## Favicon

Иконки лежат в `assets/` и уже подключены в `<head>`:
`favicon.svg` (основная, векторная), `favicon-32.png` (фолбэк 32×32),
`apple-touch-icon.png` (180×180 для iOS/Android).

Опционально: некоторые старые сервисы и боты запрашивают `/favicon.ico`
из корня сайта вслепую. Чтобы не собирать 404 в логах, положите в корень
`favicon.ico`, конвертированный из `assets/favicon-32.png`.
